Política de privacidad

Royquari Stream · Última actualización: 9 de noviembre de 2026

Quién es el responsable

Royquari Stream es una aplicación personal, operada por su propio creador (Royquari) únicamente para su canal. Contacto: TU_CORREO_AQUI.

Qué datos usa la aplicación

Con la autorización del dueño del canal, la aplicación accede a datos de su cuenta de YouTube mediante la API de YouTube Data: identificar su canal, buscar su transmisión en vivo activa, leer los mensajes del chat en vivo (nombre visible y texto), enviar mensajes del bot al chat, cambiar el título de su transmisión y subir a su propio canal los videos de resumen que él mismo edita (con título, descripción y etiquetas que él revisa). De Twitch y Kick recibe eventos del canal (seguidores, suscripciones, donaciones, canjes).

Cómo se usan

Solo para mostrar alertas y chat en pantalla durante la transmisión y para llevar los puntos de la comunidad dentro del propio canal. No se usan para publicidad, ni se venden, ni se comparten con terceros.

Dónde se guardan

Todo se almacena localmente en la computadora del streamer. Las credenciales de acceso (tokens) quedan en un archivo local y no se envían a ningún servidor propio ni de terceros. No existe una base de datos externa.

Servicios de Google y YouTube

Esta aplicación usa los Servicios de API de YouTube. Al usarla aceptás las Condiciones del Servicio de YouTube, y tus datos se tratan además según la Política de Privacidad de Google.

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso y borrar los datos

El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions (página de configuración de seguridad de Google). Al hacerlo, la aplicación deja de poder acceder al canal. Los datos guardados localmente se borran al revocar el acceso o a pedido por correo, y los mensajes del chat no se guardan más de lo necesario para mostrar el directo y sus estadísticas.

Cambios

Si esta política cambia, se actualizará esta página con la nueva fecha.
